# Westarctica Network Information Center (WNIC)

Registry project for `westarctica.net` subdomains, with a planned public information and registration site at **nic.westarctica.net**.

**Status:** bootstrap. Registration is not yet open, and nothing in this repository has permission to update live DNS. The initial architecture follows the general approach used by [is-a.dev](https://github.com/is-a-dev/register): reviewed JSON requests, validation, and eventual Cloudflare DNS publication.

The initial goals are independent registrations (including `NS` delegation), reserved institutional names, and a durable public ledger of assignments.
